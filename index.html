Busca e Validação de CEP

O seu CSV deve conter um cabeçalho na primeira linha com as colunas (a coluna bairro é opcional, mas ajuda na precisão):
uf;cidade;bairro;logradouro;numero
Nota: Se o bairro for informado no CSV e não bater com nenhum bairro retornado pela API para aquela rua, o script preencherá a coluna ceps_alternativos com as opções disponíveis para você analisar.
